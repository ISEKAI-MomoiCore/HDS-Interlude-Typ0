## C. W3：桥接动作代理（完全体 · 动作层）

目标：worker 内无 `ctx.bots` 的结构性限制解除——贴纸、QQ 空间（发说说/评论/点赞/被评论感知轮询）、内部 OneBot 动作全部经宿主代调上游。

### C1 桥接协议（双侧）

```text
Worker → 宿主请求：{ type: 'hdsi-desktop', event: 'onebot-action-request',
  payload: { requestId, accountKey, action, params, timeoutMs } }
宿主 → Worker 响应：{ event: 'onebot-action-result',
  payload: { requestId, ok, data?, errorCode?, ambiguous? } }
```

- 路由：`accountKey` → B2 的多账号注册表 → 对应上游连接器
- 语义对齐 qzone 既有约定：**传输异常/超时 = `ambiguous: true`**（可能已到达服务端，禁止自动重试，与插件 `QzoneActionError` 同族）
- 安全边界：动作白名单（宿主侧校验 action 名前缀：`send_`/`get_`/`like_`/`comment_`/`delete_qzone` 等显式清单）；params 体积上限；单故事并发上限与超时默认 30s
- 降级：旧桌面（无此 handler）不响应 → 插件侧超时回落"qzone/贴纸不可用"现状，不报错

### C2 插件侧（工作区直改，随做随同步）

| # | 事项 |
|---|---|
| C2-1 | `desktop-bridge.ts` 增加 `requestOnebotAction`（pending map 模式复用 `requestDelivery`）；`HDSI_DESKTOP_BRIDGE=1` 时安装基于它的 `qzoneCaller` 与出站表情包通道 |
| C2-2 | `sendSticker` 桌面模式分支：经动作代理 `send_private_msg/send_group_msg`，消息段用 CQ image 码（或数组段）且 `auto_escape=false`；贴纸文件经宿主本地路径直读（worker 与宿主同机，路径由 `stickers.directory` 配置保证一致），**不经 HTTP 回源**——桌面路径绕开 port:0 问题；独立部署仍走 HTTP 回源 |
| C2-3 | 被评论感知/动态轮询在桌面路径经代理调用（`qzoneCaller` 统一出口，天然生效） |

### C3 桌面侧

| # | 事项 | 验收 |
|---|---|---|

## D. UI 冻结令（即刻生效，直到 E 阶段）

**冻结范围**：`desktop/src/renderer/` 的一切视觉/布局/交互设计工作——V4–V7 原型迭代暂停（`index-v6.html`/`index-v7.html` 移出 `src/renderer/`，避免进构建产物）、不新增样式文件、不重构界面结构。

**豁免清单**（允许改动）：
1. 行为 **bug 修复**（功能正确性，非视觉）
2. 测试断言维护与既有 UI 的回归修复
3. B2-5 类**纯数据暴露**（载荷加字段，不动渲染）

**冻结原因**：本轮升级已发生 1913 行验证漂移；W2/W3 会再改桥接面。冻结 UI 把验证矩阵钉在"管道行为"上，避免每次重验都包含视觉回归。

**E 阶段（冻结解除后，独立立项）**：功能-UI 对应修改——连接中心多账号卡片与端点在线状态、表情包/空间入口与状态、（可选）V7 工作台规格对齐。届时以 V4–V7 规格为输入单独评审，不在本计划内展开。

## E. 风险登记

| 风险 | 等级 | 缓解 |
|---|---|---|
| W2 入站校验放宽引入陌生账号/跨剧本串扰 | 高 | "必须命中注册集"而非"放行全部"；B2-2 红线单测；灰度期日志审计 |
| 动作代理被上游风控（qzone/贴纸高频） | 高 | 沿用插件限流门（配额/间隔按 accountKey 分桶）；宿主侧白名单+并发上限 |
| ambiguous 误判导致重复发帖 | 中高 | 动作代理只透传插件既有 unknown 语义，宿主不自行重试；超时即终止 |
| 本地同步包身份混淆（版本字段未变） | 中 | 文件名 `+local.YYYYMMDD` 强制标记；`release/` 只读纪律；最终切割时正式定版 |
| UI 冻结期间积累的 E 阶段债 | 中 | 冻结豁免清单收窄到行为层；E 阶段立项时先做 UI 债清单盘点 |
| 验证副本再次漂移 | 中 | **每次门禁开跑前 diff src vs 副本**，不一致即重建（写进各阶段前置检查） |
