## 已实现

| 范围 | 实际修改 | 预期行为 |
| --- | --- | --- |
| 滚轮 | 实际 delta/deltaMode 转像素，再换算时间；连续指数缩放围绕鼠标锚 | 轻划细调，不再每事件跳整屏32% |
| 时间视窗 | 采用可见区坐标模型；取消三屏画布重置及原生横滚并行控制 | 视窗、轨道、刻度共用时间范围，不被下一次刷新拉回 |
| 拖拉条 | 持久DOM；独立总览范围；手势冻结范围；每帧同步轨道与滑块；手柄固定非拖动端 | 拖动跟手，不等快照返回才更新，不在上下限漂移 |
| 缩放旋钮 | 修正方向；统一20秒～14天跨度，去整分钟取整 | 标签与实际跨度一致 |
| 标尺/背景 | 同一时间刻度生成标签和格线；统一132px轨道头，独立裁剪；移除顶部假时间参考带 | 背景格线具有时间含义；宽度变化保持对齐 |
| NOW | 持久overlay在重绘区域外；仅一个总览NOW写入者；非轨道视图同步隐藏 | 新revision不删除播放头，Mixer不残留时间线 |
| 轨道显隐 | 缓存包含轨道开关及查询范围；视窗变化即时更新已加载节点 | 开关立即生效，不等新剧本 |
| 事件重叠 | 使用屏幕区间进行子行分配，不再三行循环；行距覆盖块高 | 密集事件可分别点击，不叠字 |
| 剧本阅读 | 随宽度刷新预览；窄块隐藏文字保留悬停说明；全文更新去重、离窗选中保留；Script详情列投递回执 | 放大后可读更多，状态刷新少打断阅读 |
| 数据读取 | 合并在途快照请求；消费分页，最多补8页；读取左边界前驱；未完整加载显示提示 | 减少重复IPC，避免静默把部分加载当完整 |
| 刷新 | 移除双15s周期，保留一个空闲刷新；手势绘制rAF合并、布局存储延迟写入 | 更少布局/存储工作，手势优先 |
| 布局 | 侧栏/详情尺寸依可用空间约束；ResizeObserver重测画布 | 改侧栏宽度后标尺与块同步 |
| 选区 | 共用像素转时间；松开只产生选区；暂停时右键单独请求删除并沿用确认 | 查看手势不直接接删除流程 |
| Mixer重复实现 | 删除同名旧读取/保存函数 | 首次进入即按分组显示正确控件 |
| Mixer布局 | 可自适应Grid卡片；数字精确输入+横向滑杆、布尔按钮、枚举下拉、常显说明 | 配置不再全部挤成小竖推子 |
| Mixer草稿 | 按故事存储，异步读取令牌；切组叠加草稿；串行保存，确认仅清本次未再修改字段 | 切组/慢请求不丢编辑 |
| Mixer保存 | 显式“保存”“保存并重载”；重载等待写入完成 | 不再与800ms延迟保存竞争 |
| Mixer参数语义 | 未指定标注继承，不伪造有效默认值；采样指向显式主叙事provider；宿主校验boolean和枚举 | 控件类型与落盘类型一致，避免误改第一个provider |
| 其它闭环 | 离开Console显式撤下；新建/分支取消绑定；删除重复Configure保存与旧YAML回写覆盖路径 | 减少跨Surface覆盖和双保存副作用 |

## 验证结果

- `node --test scripts/test-timeline-model.cjs`：5项通过。覆盖缩放锚点/逆变换、手柄极限、输入积分、50并发事件独立子行、重复函数声明。
- `npm run test:runtime`：既有34项通过。
- `npm run typecheck`、`npm run build`：通过。
- `scripts/test-studio-ui.cjs`：隔离 headless Edge 页面，注入假的宿主接口；验证冷启动无错误、滚轮小幅位移、刷新后NOW仍连接、轨道显隐、Mixer类型/草稿/保存、拖拉条后刷新不重新居中。
- 在1280和1440宽度下测量：标尺与轨道左边界误差≤1 CSS px，NOW与轨道时间映射误差<2 CSS px；已查看轨道与Mixer截图。
- 同一界面测试支持 `UI_TEST_DIST=1`，已用于验证实际构建产物入口。

测试浏览器使用临时独立会话，没有连接真实桌面Worker、账号或数据库。UI测试依赖可用的puppeteer-core和Edge；其它机器可通过`UI_TEST_BROWSER`指定浏览器路径。

## 当前边界

- 密集事件本轮采用可滚动子行，尚未实现远景聚合/Canvas虚拟化。非常大窗口仍可能需要后续性能工程；没有宣称达到所有机器60fps。
- 分页有上限，并明确显示部分加载。前驱查询沿用核心现有接口；完整任意跨窗区间查询仍受核心API能力约束，没有改安装的HDSI包。
- Mixer显示配置与草稿，不声称显示Worker实时有效默认值；无显式主叙事provider时拒绝写采样参数，需先在模型配置指定目标。
- 系统125/150/200%缩放、Electron原生Console、多显示器、真实长时消息流尚未做完整人工回归。隔离浏览器通过不能替代这些验证。
- 未重启当前桌面窗口；已运行页面需要重新打开项目后才加载新dist。

不要将本报告简写为“旧37项全部完成”。本轮完成了用户重点反馈的交互、布局及配置保存闭环，以上性能和运行环境边界仍需后续实机验证。
