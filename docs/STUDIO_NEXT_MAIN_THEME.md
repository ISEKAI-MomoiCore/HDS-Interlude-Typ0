## 与 RC57 数据的对应

- **时间线摘要**：来自当前 `timelineRange` 投影，不作为整个故事的累计回合数。标题使用“剧本条目”，不把条目数量叫作回合数。
- **场景**：按时间寻找活动场景；没有活动场景时显示最近场景。没有投影时不编造场景内容。
- **事实**：总览预览最多四条、Inspector 最多三条；数量仍按投影事实总量计算，不按预览截断后的数量计算。
- **预计划**：展示实际有效期、修订和时区；跨日窗口带日期，不推断下一步路由或行动。
- **投递摘要**：来自宿主 Outbox 状态汇总；未取得宿主投影时显示“尚未可读”，不误显示零。
- **活动记录**：来自投递历史和宿主错误；保留未知、可重试失败、不可重试失败的区别。
- **来源渠道**：仅当条目提供 `metadata.channel` 时显示“近期出现”。RC57 常规 range 投影可能不提供该字段；缺失不等于端点离线，更不冒充账号在线状态。
- **模型用量**：展示宿主返回记录的日期；最近可用日期不一定是今天，因此不再统一标记为“今日”。

## 展示侧稳定性

- 修复共享布局中的残留非法 CSS、预览轨道不可见、clip 绝对坐标未生效等问题。
- 默认主题使用低对比纸面网格；其他主题保留原网格颜色回退。
- 总览与时间线直接切换，不复制轨道、不重写原始时间数据。
- 宿主投影刷新会更新 HUD；同长度账本行发生状态变化时也会刷新详情，不依赖新增行。
- 更新 HUD 时保留阅读滚动位置和键盘焦点，避免定时刷新打断操作。
- 投递详情优先兼容持久化记录的 `lastError`，移除“尚未实现历史 API”的过期说明。
