快捷键与术语

快捷键

Ctrl + K
全局功能搜索（按目标找设置入口）
?
打开本帮助
F5
刷新时间线投影
Space
循环切换相位：运行 → 静音 → 暂停（焦点在输入框/按钮时不生效）
1 – 4
切换 Overview / Session / Timeline / Mixer 视图
Ctrl + 滚轮
以鼠标为锚缩放时间轴；Shift + 滚轮 平移
Shift + 拖选
在时间轴上框选区间（剧本须为暂停态），松开后可删除该区间
Esc
关闭菜单 / 清除选区与拖拽状态
双击时间旋钮
重置缩放为默认 14 小时并回到 NOW

隐藏手势

故事条、时间轴块、轨道头、底部拖拉条都有右键菜单（分支续写、复制全文、隐藏轨道、回到 NOW 等）。桌面端为鼠标交互优化，触屏设备不可用右键菜单。

术语

Worker
承载一个剧本的 Koishi 子进程；「加载/卸载」即启停它。
bridge
桌面宿主与 Worker 内 HDSI 插件的通信链路；「bridge 就绪」= 时间线可读。
运行 / 静音 / 暂停
运行=正常收发与推进；静音=仍生成剧本但不发送消息；暂停=停止推进，期间消息进收件箱。
Inbox / Outbox
收件箱=等待投递给角色的入站消息（可回放）；出站=角色消息的发送状态账本。
Script / Receive / Send
剧本主轨（模型写出的生活原文）/ 收到的消息 / 已发出的消息。
Alter
情绪惯性：氛围的临时偏移，会随时间衰减。
Facts & Scenes
长期事实与场景的结构化投影（可从剧本原文重建）。
Schedule Preplan
角色未来半天的日程计划；计划不等于已发生。
Compaction
后台记忆压缩：把长场景整理为摘要与事实。
OSD 指标
WRK=Worker 占用，MEM=渲染进程堆内存，RPH=最近一小时消息数，GAP=最近一次收发间隔（近似）。
